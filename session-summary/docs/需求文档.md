# 会话摘要悬浮框（dsh-session-summary）需求文档

确认时间：2026-10-24。

## 背景

Codex 桌面版的对话右上角有一个可固定的摘要卡片：顶部是项目名，下面依次是变更、子智能体和来源。OpenAI 没有为它单独写文档，GitHub 上的用户称它为 "pinned summary" 或 "right-side task summary panel"。可以找到的公开描述如下：

- [Work with files](https://learn.chatgpt.com/docs/artifacts-viewer)：桌面版的对话侧栏 "can surface the agent's plan, sources, generated files, and chat summary"。
- [Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)：子智能体分为只读的 Active / Done 列表。可以打开已完成的子智能体查看结果；面板本身不能停止或引导子智能体。
- [Troubleshooting](https://learn.chatgpt.com/docs/reference/troubleshooting)：变更基于 Git 状态，有 "Last turn" 视图。
- [WebMCP](https://learn.chatgpt.com/docs/webmcp)：Recently used 会打开 Sources，用于查看调用记录。
- [openai/codex#40270](https://github.com/openai/codex/issues/40270)：pinned summary 包含 Created tasks（状态为 Starting / Working / Done / Failed）和 Subagents。
- [openai/codex#38908](https://github.com/openai/codex/issues/38908)：面板显示子任务状态和计时。已结束的任务仍显示 Working 是一个已知 bug，本插件以实时会话状态为准。

## 已确认的范围

1. **交互和 Codex 一致**：对话页头右上角放一个按钮，点击后显示或隐藏悬浮卡片。卡片覆盖在对话区右上方，不占用对话宽度，**不做成右侧栏标签页**。卡片可以固定：固定后切换会话、刷新页面仍保持打开；未固定时，点击外部或按 Escape 关闭。
2. **板块全部加入**：
   - 项目：工作目录名。
   - 变更：本会话各轮改动的文件及 +/− 行数，点击打开原生 review 对比。
   - 子智能体：运行中 / 已完成状态、耗时、token 用量，点击在右侧栏打开子会话。
   - 来源：网页搜索 / 抓取、MCP 服务器 / 工具、技能、@ 引用的文件 / 会话。
   - 计划 / 待办。
   - 生成文件：通过 `present` 交付的文件。
   - 后台任务。
   - 关联会话：父会话、fork 来源、本会话派生的分支。
3. **代码位置**：放在 `E:\dsh-plugin\session-summary`，和 `E:\dsh-plugin\side-branch` 分开存放。
4. **验证方式**：只做单元测试和隔离测试并打包，不安装、不重启当前 DSH；开发完成后告诉用户怎么安装，由用户自己安装。

## 行为约束

- 只读展示和原生导航：插件不发送模型请求，不往会话里写入任何内容，不改变 Session 配置。
- 状态以实时会话数据为准，已结束的子智能体或任务不显示为运行中。
- 数据缺失时（例如 Host 重启后，之前轮次的变更摘要已不存在）显示说明，不编造内容。
- 浅色 / 深色主题都使用 DSH 原生设计变量，中英文界面都有对应文案。
