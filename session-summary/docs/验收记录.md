## 预览中发现并修复的问题

1. **固定后刷新页面，卡片会不可见**：首次挂载时，子组件的 layout effect 先于父组件的 ref 赋值执行，读不到锚点位置。已改为用 callback ref 把锚点元素作为状态传给子组件。
2. **中文全角标点紧跟在 @ 文件引用后面时**，后面的文字会被并入路径。现在遇到全角标点就截断。
3. **改动摘要读取失败后会无限重试**：失败结果现在会保留，只有点击“重试”或“刷新”才会重新请求。

## 尚未验证的部分

以下需要你安装后在真实页面中确认：

- 按钮在真实页头中的位置和间距，以及与右侧栏展开按钮、`dsh-better-sidebar` 按钮的相对位置。
- 卡片在 Windows 桌面标题栏布局下的定位、层级（z-index），以及与右侧栏全屏、浮动面板叠加时的表现。
- 原生 review、子会话、内置浏览器、计划、文件预览等标签页的实际打开效果。
- `api/changes.summary` 在真实 Host 上的返回（插件与原生改动卡片使用的是同一个路由）。
- 卡片打开时，在输入框中按 Escape 能否关闭卡片，并且不会误触“连按两次 Escape 停止运行”。

## 安装后的页面验收清单

1. 打开一个已有对话的会话，确认页头右上角出现按钮，位于右侧栏展开按钮的左边。
2. 点击按钮，确认卡片出现在对话区右上方，不挤占对话宽度；点击外部或按 Escape 后关闭。
3. 固定卡片，切换到另一个会话再刷新页面，确认卡片仍然显示且内容已切换到当前会话。
4. 分别点击变更文件、子智能体、网页来源、交付文件，确认都在右侧栏打开对应的原生页面。
5. 切换浅色和深色主题，确认卡片配色和原生菜单一致。
