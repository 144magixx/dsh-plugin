# 图片标注 · Image Annotate

在 DSH 输入框里**双击待发送的图片**，进入全屏编辑模式，加上文字、圈画、箭头等标注。点「保存」后，编辑后的图片自动替换输入框中的原图，位置不变。

纯前端插件，没有 Host 路由、订阅、后台进程或存储，不参与桌面更新的请求排空。

## 用法

| 操作 | 效果 |
|---|---|
| 双击输入框中的图片缩略图 | 打开编辑器（悬停时缩略图右下角有铅笔标记） |
| 单击缩略图 | 照常打开原生「查看原图」（会等约 0.3 秒，用来区分双击） |
| 聚焦缩略图后按 `E` | 用键盘打开编辑器 |

### 工具

| 工具 | 快捷键 | 说明 |
|---|---|---|
| 选择 / 移动 | `V` | 点选标注后可拖动、方向键微调（Shift 每次 10px）、`Delete` 删除；双击文字可重新编辑 |
| 画笔 | `P` | 自由绘制；单击画一个点 |
| 荧光笔 | `H` | 半透明粗笔 |
| 矩形 | `R` | 按住 Shift 画正方形 |
| 圆圈 | `O` | 按住 Shift 画正圆 |
| 箭头 | `A` | 按住 Shift 按 45° 对齐 |
| 序号圆点 | `N` | 单击放置自动递增的编号圆点（1、2、3…） |
| 文字 | `T` | 单击输入；Enter 完成，Shift+Enter 换行，Esc 取消；支持中文输入法 |
| 马赛克 | `M` | 框选区域打码 |

8 种颜色和 细 / 中 / 粗 三档。先选中标注再点颜色或粗细，会直接修改这个标注。粗细按图片分辨率换算，大图小图上的标注观感一致。

撤销 `⌘/Ctrl+Z`，重做 `⇧⌘Z` / `Ctrl+Y`，保存 `⌘/Ctrl+S`。`Esc` 先取消选中；没有选中时关闭编辑器。有未保存的标注时会先确认。

## 保存时会发生什么

- 按原图分辨率导出。PNG、JPEG、WebP 保持原格式和文件名；JPEG/WebP 质量为 0.92。其他格式（如 GIF）导出为 PNG，扩展名随之改为 `.png`，动图只保留第一帧。
- 输入框的原生接口只有“移除”和“追加”。为了保持顺序，插件会移除被编辑的图片及其后面的附件，再按原顺序把「编辑后的图片 + 后面的附件」加回去。后面的附件会重新上传，使用的仍是原来的文件。
- 如果输入框拒绝新图片（例如超过单张或总大小限制，原生提示会照常出现），插件会自动把原图和后面的附件按原顺序放回去。编辑器保持打开，标注不丢，可以撤销一些内容后再保存。
- 输入框正在发送等不可编辑状态时，插件不会移除任何内容，只提示稍后再保存。
- 没有任何标注时点保存，直接关闭，不替换原图。

编辑器打开期间，键盘、粘贴和拖放事件不会传到页面的其他快捷键或输入框。

## 实现

- 包装 `conversation.input.attachments` 的原生条目（ui-attachment 的附件栏），优先级比原生高一级，原生组件照常渲染。原生条目变化时会自动重新包装；包装失败时保留原生附件栏。
- 根据缩略图 `<img>` 的 `src` 与附件的 `previewUrl` 匹配双击到的是哪张图；上传失败、被拒绝的缩略图保留原生的重试或提示行为。
- 编辑器渲染在 `document.body` 的 Portal 中，使用矢量标注模型（坐标是图片像素），撤销历史最多 100 步。导出优先用 `OffscreenCanvas.convertToBlob`：`HTMLCanvasElement.toBlob` 在空闲时段编码，页面繁忙（例如正在流式回复）时可能拖慢数秒。
- 替换流程按渲染推进：等原生附件列表确认移除后再追加（原生 intake 读取的是创建它那次渲染的附件列表），然后按 File 对象确认追加成功；2.5 秒内没有出现则视为被拒绝并恢复。恢复后编辑目标按 File 对象重新定位，所以可以直接重试保存。

## 开发

```sh
npm run check          # 语法检查
npm test               # 纯逻辑单元测试
npm run test:browser   # 构建真实壳页面（只读提取本机 DSH 的 React、ui-primitives 与原生 ui-attachment）
```

`test:browser` 生成 `tests/browser/.real/`。在插件目录下启动任意静态服务器后，打开 `/tests/browser/.real/index.html`。页面挂载原生附件栏，并模拟输入框的“只追加”附件存储和拒绝逻辑：`seed()` 添加 3 张图，`rejectNext = true` 让下一次追加被拒绝，`locked = true` 模拟发送中，`state()` 查看当前附件。验证截图在 `artifacts/`（不提交）。

## 已知限制

- 单击查看原图会延迟约 0.3 秒（用来识别双击）。键盘回车或空格打开原图不受影响。
- 只编辑输入框里尚未发送的图片；会话历史中的图片不在此插件范围内。
- 被编辑图片后面的附件会重新上传。
- 编辑器固定为深色界面，不跟随主题。
