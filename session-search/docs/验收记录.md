## 验证边界

本次没有可用的浏览器控制工具，因此没有声称完成实际 Cmd+F 键盘操作、鼠标点击、浅深主题视觉检查或图标显示的端到端验收。实时 Slot 激活只能证明注册状态，不能替代这些操作。

当前 DSH 没有公开的任意聊天消息滚动/高亮入口。插件在自己的搜索面板中定位并高亮命中上下文；“打开会话”保留原生阅读位置。一个结果代表一条命中消息，消息内多次出现的关键词不会重复计数。

首次读取特别大的冷会话仍受 DSH 完整日志读取开销影响。搜索过程中若某个历史会话无法读取，面板明确显示警告，不把它当作成功搜索。
