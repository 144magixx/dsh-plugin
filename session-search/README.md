# 会话搜索 · Session Search

在 DSH 中按 **Cmd+F**（Windows/Linux：**Ctrl+F**）搜索当前会话，按 **Cmd+Shift+F** / **Ctrl+Shift+F** 搜索所有会话。支持中文片段、英文、路径和代码片段，不需要等待聊天历史滚动加载。

## 使用

搜索面板提供三个范围：

- **当前会话**：查找当前主视图中的会话，按消息顺序展示命中内容。
- **会话标题**：通过标题找到历史会话。
- **所有会话正文**：按会话分组展示正文命中，可选择工作区，并勾选归档会话。

默认只搜索用户消息和助手回复中的文字、Markdown 和代码。勾选“包含工具内容”后加入工具调用参数及文字输出。消息内的思考过程、系统提示和附件文件内容不参与搜索。匹配方式为忽略大小写的普通文字子串；正则符号按文字处理。

点击结果可查看命中消息和附近上下文，关键词在搜索面板内高亮。方向键选择结果，Enter 打开会话，Esc 关闭；“打开会话”进入原生聊天。一个结果代表一条命中消息，多次出现的关键词仍计作一条。会话标题栏和侧栏也提供搜索按钮。

历史较多时分批搜索。面板显示已扫描会话数，并提供继续加载入口；扫描尚未完成时不会把空批次当成“没有结果”。修改关键词、范围或关闭面板会取消旧请求。新落盘的消息可通过重新搜索获取。

## 当前版本边界

- DSH 0.2.1-rc.3 没有公开的插件接口用于任意消息精确滚动和原文高亮，因此高亮与上下文阅读发生在搜索面板内；“打开会话”不保证滚动到命中消息。
- 尚未在客户端打开过的子智能体会话，搜索面板提供“打开父会话”，以便从原生子智能体入口进入；已知会话及普通分支直接打开。
- 归档会话可以搜索、预览；要在原生聊天继续交流，请先在 DSH 中恢复会话。
- 尚在流式输出的助手消息在落盘后参与搜索。
- 单页最多扫描 24 个会话或 4000 个日志事件，最多返回 100 条命中；继续分页可覆盖全部历史。首个冷读需要 DSH 读取该会话完整日志，特大单会话可能较慢。
- 上下文目标消息按每段最多 20000 字符读取，临近消息最多 3000 字符，截断状态会明确标注。原始日志不会因搜索修改。
- 搜索覆盖当前 DSH 进程能访问的会话库，不跨其他独立的 DSH 数据目录。

## 安装

此插件为纯 JavaScript，无构建步骤、无运行时依赖或安装脚本。

1. 克隆本仓库。
2. 在 DSH 的“插件 → 安装第三方插件”中填写 **session-search 子目录的绝对路径**。
3. 启用“会话搜索”。如果当前页面未加载新插件，刷新已有 DSH 页面。

命令行安装：

```sh
dsh plugin --profile desktop add /absolute/path/to/dsh-plugin/session-search
```

Desktop 快捷键通过 DSH 快捷键服务注册；Web 中的普通 Cmd/Ctrl+F 由插件的可清理键盘监听处理。插件禁用后释放快捷键、监听器和搜索请求。

## 开发与测试

```sh
npm test
npm run check
npm run test:integration
```

集成测试从本机 DSH 安装包只读提取原生依赖，使用独立的临时会话、JSONL 存储和工作区；不读取用户会话、不调用模型、不启动替代 Web 服务。`DSH_TEST_ASAR` 可指定其他安装位置。测试数据在退出时清理，提取依赖位于忽略的 `scripts/.runtime/`。

后端的只读 `session_find` 工具与界面共用搜索和上下文实现，支持 `action: search | context`。分页游标与关键词及过滤条件绑定，插件重载后需重新搜索。
