# 任务异常提醒 · Task Alerts

0.2.0 将原插件精简为异常提醒。右侧原有卡片只显示跨会话提醒，保留会话跳转、单条已读、一键全部已读和折叠未读计数。

## 行为

- 任务以错误、输出上限或意外中断结束时，记录异常会话、时间和错误摘要。
- 在其他会话工作时仍可看到提醒；点击「查看会话」通过原生导航进入对应会话。
- 被动观察 Harness 自身的重试记录：连续重试超过两分钟才提示，短暂恢复不会延迟误报。插件不发起重试、不恢复任务、不回答问题。
- 单条或一键已读只管理提醒。批量已读绑定读取时的快照，包括分页之外的提醒，随后到达的新异常保持未读。
- 每个会话保存最新一条异常和已读状态，刷新、切换会话及 Host 重启后保留。插件启动时核对已有提醒，运行期间根据原生事件更新；界面每三秒读取轻量索引。
- 主动 Stop 不生成新的失败提醒。恢复执行、完成或停止会更新已有提醒的状态。
- 断线时保留上次记录并提示重连。应用内提醒需要 Host 和页面在线，不发送桌面或外部消息。

## 从任务守护升级

自动重试中间件、恢复审查、问题倒计时、守护设置页、启动项设置入口和 `task_guardian_status` 工具已移除。插件不再注册请求恢复或任务控制钩子，也不修改 Harness 自身的重试策略。

保留原包标识 `dsh-task-guardian`、HTTP 前缀和存储域，以便已有安装原位升级。会话提醒和已读记录沿用；旧会话记录中的守护设置与运行状态在迁移时移除。历史审计与独立系统登录偏好不作为自动执行授权使用，本版没有修改系统登录项的能力。

模型可通过 `task_guardian_alerts` 查询跨会话未读提醒、标记单条已读，或用列表返回的 `readToken` 一键全部已读。

## 位置与安装

卡片沿用 `capability-selector.accessories` 插槽，位于原本右侧的卡片栏。显示该入口需要启用提供此插槽的“外部能力”插件。

通过原生插件管理器安装本目录。若管理器要求先移除旧版本，移除包后再安装；提醒存储独立于包目录。以管理器返回的生效状态为准，更新后可刷新现有 Harness 页面。

