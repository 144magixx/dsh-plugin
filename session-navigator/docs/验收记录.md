## 验证边界

本次浏览器桥接只绑定到另一个已打开的网站，未连接当前 Harness 窗口，已释放绑定并保留用户页面。没有启动替代浏览器或仿制页面，因此不宣称完成真实窗口截图、浅深色主题视觉或按钮点击的端到端验收。Client 注册检查与逻辑测试不等同于视觉验证。

首次进入会话导航后如当前窗口尚未显示入口，可刷新 Harness 页面。插件使用宿主主题变量和现有 UI 扩展点，不替换原生会话列表。

## 0.1.1 悬停视觉修复

- 按用户确认的预览实现主题自适应磨砂底板：约 90% 不透明度、12px 背景模糊，文字保持不透明；无模糊支持或减少透明偏好时回退为实色。
- 悬停改用独立紧凑组件，摘要和提问各两行，两个历史话题标签及 `+N`，一行相对时间；完整详情仍保留全部信息。
- 66 项自动化测试通过，新增三个用例覆盖紧凑预览的数据保留、失败/暂停状态和相对时间边界。
- 已只读核对当前宿主实际代码和静态资源：会话卡是 HoverCard，命名会话的容器为 `role=button`，不能按 `role=tooltip` 选取。样式使用原生 CSS 模块局部类名与本插件 `.dsh-nav-hover` 标记共同限定，只修改对应的宿主卡片。
- 独立代码复核确认选择器与原生结构一致，并补充原生卡片的窄窗口剩余宽度约束；保留宿主内联定位、复制标题和运行状态。复制成功的一秒反馈仍使用宿主原样。
- 宿主 CSS 类名结构是当前版本的兼容依赖，后续宿主升级需重新检查。常规色彩与背景均引用主题变量，未设置整个卡片的 opacity。
- 当前 GUI 对未认证页面请求返回 HTTP 401。本次没有绕过认证、启动替代浏览器或把合成预览当作运行截图；浅深色及窄窗口真实截图验收仍未完成。更新后需要刷新 Harness 页面查看新样式。
