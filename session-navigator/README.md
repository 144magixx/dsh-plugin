# 会话导航 · Session Navigator

让会话保留原来的标题，同时展示最近聊到的话题，便于从大量会话中找回想继续的讨论。

- **两行会话列表**：稳定标题 + 最近话题；摘要尚未覆盖新内容时，立即显示最近提问。
- **详情与悬停预览**：完整详情保留全部信息；悬停使用跟随浅深色主题的半透明磨砂小卡片，摘要与提问最多两行，历史话题最多显示两个标签，时间改为相对时间。原生会话列表和导航列表采用一致的预览样式。
- **查找与排序**：按工作区筛选，搜索标题、近期话题、缓存摘要和最近提问，按最近访问或内容更新时间排序。
- **原生导航**：打开原来的会话，保留 DSH 的原生会话界面。从原生侧栏打开会话也会记录最近访问。
- **独立后台摘要**：默认使用已有 `codex-relay` 中的 `gpt-6-luna`，不创建子 Agent，不向原会话插入摘要请求。
- **失败回退**：模型慢、超时或不可用时，继续显示最近提问与已有摘要。浏览、悬停和打开会话都不等待模型。

纯 JavaScript，**零运行时 npm 依赖、无需构建**；React 与所需服务由 DSH 提供。适用于 Windows 和 macOS 的 DSH Desktop / Web GUI。

## 安装

获取仓库：

```sh
git clone https://github.com/144magixx/dsh-plugin.git
```

在 DSH 的 **插件 → 添加插件旁的下拉箭头 → 安装第三方插件** 中，填写 `session-navigator` 子目录的绝对路径：

| 系统 | 示例安装目录 |
|---|---|
| macOS | `/Users/<你的用户名>/dsh-plugin/session-navigator` |
| Windows | `E:\dsh-plugin\session-navigator` |

安装后启用 **会话导航**。侧栏新增“会话导航”入口，原生会话列表继续保留。不要把整个仓库根目录作为这个插件安装。

默认模型路由为 `codex-relay / gpt-6-luna`。请先在 DSH 模型设置中配置并确认该模型可用；插件复用既有模型服务，不携带 API Key 或服务地址。使用其他服务商或模型时，按[配置说明](<docs/使用指南.md#配置>)修改 `provider` 和 `model`。

## 怎么用

打开侧栏的“会话导航”，先浏览两行会话列表，也可以输入关键词、选择工作区或调整排序。单击会话查看右侧详情，双击或点击“打开会话”进入原生对话；键盘支持方向键选择、Enter 打开。

以下为虚构示意，不来自真实会话：

```text
周末阅读笔记
最近：版画中的留白与构图
```

新问题出现后，第二行先显示问题原文。摘要生成完成后，再自动换成简短话题。详情会标明“之前的摘要”，避免把未更新的概括误认为最新内容。

- **更新摘要**：立即排入后台队列，完成后自动更新显示。
- **暂停自动摘要**：只暂停该会话的自动生成；仍可手动更新。
- **包含归档**：可查阅归档会话的已有信息，打开前需在原生侧栏取消归档。

本插件按近期线索找会话，**搜索范围不包含整段历史正文**。要检索所有历史消息，可搭配仓库中的[会话搜索插件](<../session-search/README.md>)。

## 自动更新与回退

启用时，默认对最多 **12 个最近更新的非归档普通会话**检查是否需要后台补摘要；更早的会话在实际打开时按需补齐。之后在一轮对话完成时更新，不对每个 token 或中间工具调用生成摘要。

默认单次模型超时 **20 秒**、并发 **2**、最多 **48** 个待处理会话；连续 **3** 次生成失败后，自动任务进入 **60 秒**冷却期。旧摘要继续保留，用户可查看错误并手动重试。插件不会自动切换到其他模型。

悬停、列表读取和详情读取不会调用模型。后台通过变更通知更新界面，不轮询模型状态。更完整的操作说明、配置范围和故障处理见[使用指南](<docs/使用指南.md>)。

## 数据与边界

- 原会话日志是内容来源；插件不改标题、不重写消息，不向会话追加摘要内容。
- 最近话题、摘要、暂停状态与访问时间由 DSH 的 `storageDomain` 持久化，重启后可复用。
- 模型只接收有长度上限的近期用户/助手正文和必要的旧摘要线索。运行时提示、工具日志和子 Agent 通知不作为讨论正文。
- 导航面向普通会话，不列出子 Agent 任务。自动摘要会跳过归档会话。

## 开发与验证

需要 Node.js 22 或更新版本。在插件目录运行：

```sh
npm run check
npm test
```

测试仅使用**合成事件与合成会话样例**，仓库不包含真实对话测试数据。测试覆盖内容提取、摘要格式、状态与请求竞态、访问记录、流式更新、取消和降级行为。

已完成 66 项自动化测试，以及安装、真实模型刷新和缓存复用验证。界面组件已在当前 Client 注册；本次未完成真实窗口截图验收。具体范围见[验收记录](<docs/验收记录.md>)。
