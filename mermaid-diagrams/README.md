# 会话图表 · Mermaid

在 DSH 助手回复中直接渲染 Mermaid 代码块，支持流程图、时序图、类图、状态图、ER 图、甘特图、思维导图等 Mermaid 内置类型。

## 使用

让助手使用带 `mermaid` 语言标记的 Markdown 代码块。顶层代码块闭合后显示图形，已经加载的历史回复也适用。没有语言标记但首行是 `sequenceDiagram`、`flowchart` 等明确 Mermaid 声明的代码块也会识别。

- 卡片外观与 DSH 原生代码块一致；头部显示中文类型名（流程图、时序图……）和四个图标按钮：查看源码、复制源码、放大查看、下载 SVG / PNG。
- 配色跟随 DSH 明暗主题：节点浅蓝底加蓝色描边，判断节点浅琥珀色，连线和箭头为灰色；字体与正文一致。
- 图表按聊天栏宽度自适应；缩小到 72% 仍放不下时改为横向滚动。
- 放大窗口：默认适应窗口，支持 Ctrl/⌘ + 滚轮或触控板双指缩放、拖动平移，快捷键 `+`、`-`、`0`。
- 语法错误时显示“第 N 行有语法错误”（悬停查看 Mermaid 完整报错）并保留源码。
- Mermaid 随插件打包，不使用 CDN，不上传会话内容。

## 性能

- 页面出现图表后在空闲时预加载引擎；距离可见区域约一屏时开始绘制。
- 引擎只在配色变化时重新初始化。
- 绘制结果（包括错误）按「源码 + 主题」在内存中缓存 60 份：折叠展开、切回会话时直接显示，不重新绘制。
- 直接插入安全过滤后的 SVG，不再转成图片。
- 布局使用 Mermaid 经典的 dagre，未打包 ELK 布局引擎（约 1.5 MB）；`flowchart-elk` 会提示不支持并保留源码。
- 每次绘制记录 `performance.measure('dsh-mermaid:render')`，可在开发者工具的 Performance 面板查看。

## 安装

在 DSH 插件管理器中安装此目录或打包后的 npm 文件。安装后的名称为「会话图表 · Mermaid」。停用插件即恢复原生源码显示。

源码适配当前 DSH `0.2.1-rc.5`。这是独立插件，不修改 DSH 安装文件或会话日志。

## 实现边界

当前 DSH 没有 Markdown 代码块渲染扩展接口。本插件通过 `conversation.chat.node` 的 `assistant-step` 渲染键适配，只拆分含图表的正文；其他正文仍交给原生 Markdown，推理和图片通过插件自有子插槽转接原生组件，轮次操作与附件由 DSH 保留。未知的子插槽结构会使适配器退出并保留原生会话。

- 只识别行首无缩进、闭合的反引号或波浪线围栏。列表、引用、缩进中的代码块不拦截；外层代码示例中嵌套的 Mermaid 不拦截。
- 构建时将 Mermaid 的临时测量、tooltip 和布局容器重定向到插件自有绘图容器；不改写宿主的 document 或 d3，全程串行绘制。
- 用户消息与思考过程不渲染为图表。
- 正文跨图表分成多个原生 Markdown 区段；引用链接定义会补全，但跨段脚注编号、复杂列表布局可能与单次原生渲染不同。
- 不支持 Mermaid 自定义配置指令、YAML 前置信息、外部图片资源和点击回调。统一主题与严格模式适用于所有会话。
- 单图最多 30,000 字符、400 条边；错误时保留源码。
- 图表强调色是插件自带的配色（DSH 的品牌主题色在浅色下为近黑色、深色下为白色），背景与文字颜色读取 DSH 主题令牌。
- DSH 升级后需重新验证会话适配层。

## 开发

Node.js 22+，pnpm：`pnpm install --ignore-scripts`、`pnpm run build`、`pnpm test`。

运行时文件为 `index.js` 与预构建 `lib/client.js`；没有安装脚本或运行时 npm 依赖。`scripts/mermaid-plugin.mjs` 是构建期 Mermaid 适配（自有渲染容器、禁用外部图片、替换 ELK），构建会校验适配点全部生效且未打包 ELK。界面文案有中文和英文，图标为原创。

## 本次验证（0.2.0）

- 构建与 JavaScript 语法检查通过；客户端包 3.88 MB（0.1.1 为 5.41 MB）。
- 10 项自动测试通过；5 项图表解析测试因 Mermaid 消毒器需要浏览器 DOM 而明确跳过。
- 组件浏览器测试：用 React 18 直接渲染 `src/diagram.jsx`，使用与插件相同的构建期适配和 DSH 明暗主题令牌，实际点击验证了源码切换、复制、SVG / PNG 导出（PNG 文件头正确）、放大窗口缩放 / 拖动 / 适应 / Esc 关闭、语法错误提示与重试；渲染期间页面根部没有新增节点。绘制耗时 13–44 ms / 图（引擎已预加载），重新挂载 6 张卡片 5 ms 且零次重新绘制。
- 组件测试页不是 DSH 本身：浏览器自动化访问 DSH Desktop 页面返回 HTTP 401，会话内的最终显示仍需在 DSH 中刷新页面确认。
