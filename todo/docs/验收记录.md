## 浏览器验证（非 DSH 本体）

[`scripts/live-preview.mjs`](../scripts/live-preview.mjs) 用真实的 `lib/service.js` HTTP 处理器（内存存储）和真实的 `lib/client.js`（React 18 UMD）在 Chromium 中跑交互，已验证：

- 勾选完成后事项留在原位，计数随之更新。
- 回车连续新建，Esc 退出新建。
- 行内改名。
- 详情面板改时间、旗标、备注、关联当前对话后，服务端数据一致。
- 新建紫色列表后自动切到该列表，标题显示紫色。
- 服务端新增的事项（模拟 Agent 写入）在 1 个轮询周期内出现。
- 到点横幅弹出一次；点「10 分钟后」后横幅关闭，提醒时间顺延约 10 分钟。
- 点会话标签触发打开对应会话。
- 卡片里新建的事项默认今天到期，并关联当前对话。

截图：[静态渲染对照](preview-static.png)、[浏览器交互后](preview-browser.png)。

验证中修复了两处问题：

- 样式重置规则的优先级盖过了蓝色按钮颜色，改用 `:where()`。
- 样式改用 `dangerouslySetInnerHTML` 注入，避免 SSR 转义 `>` 选择器。
