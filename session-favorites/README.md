# 常用对话 / Favorite conversations

在当前右侧卡片栏（外部能力卡片下方）显示跨会话共享的收藏列表。

- 点击 **加入当前对话**，或右上角 **＋** 后搜索标题、工作区并添加。
- 点击对话标题，通过原生导航打开；当前对话高亮。
- 点击行末 **×** 只取消收藏，不删除、归档、改名或停止原会话。
- 收藏按添加顺序排列，保存到当前 profile 对应的 storageDomain；刷新和重启后保留。
- 支持中英文本、主题色、键盘操作、折叠卡片、空状态和错误重试。
- 收藏变化通过同源短期变更订阅同步；每个请求最多 2.5 秒，无进度轮询，不调用模型。
- **绿点**：收藏后有新成功结束的轮次尚未查看；打开该会话且窗口处于前台时保存已读游标。失败、取消和旧历史不会触发新的绿点。
- **黄点**：存在待回答的结构化问题或计划确认；优先于绿点。问题超时后仍可回答时继续显示；仅浏览会话不会清除黄点。
- 进行中的会话（正在运行一轮）在行首显示转圈标记；等待回答的黄点优先于转圈，运行结束后转圈消失，若有新完成结果则显示绿点。
- 卡片折叠后标题仍显示聚合提醒。状态不可读取时使用灰点与提示，不伪报完成。
- 已读游标与收藏一起持久保存，确认某次结果不会误清掉随后完成的新结果。提醒仅观察状态，不代用户回答问题或批准操作。

## 环境

卡片使用现有 `dsh-capability-selector` 的 `capability-selector.accessories` 插槽，因此该插件需启用。它与截图中的“外部能力”“任务守护”处于同一个卡片容器。原生右侧面板展开或宿主卡片栏隐藏时，卡片随容器隐藏。

采用当前核验的 DSH `0.2.1-rc.5` 接口；运行文件不依赖编译器或额外 npm 运行库。目录安装由 Harness Plugin Manager 完成。

## 接口

`session_favorites` 工具提供 `list`、`search`、`add`、`remove`。添加/移除要求明确的 `sessionId`；搜索支持标题、工作区路径/名称和 ID，使用 `offset`/`limit` 分页。HTTP UI 与工具共用同一个业务实现。搜索只列出普通对话，不列出子智能体。

数据只包含收藏 ID、添加时间及作为回退的标题/路径；显示时优先读取最新会话标题。会话暂时不可读时保留收藏并显示不可用，不自动删除。归档会话沿用原生导航的打开限制，可在原生侧栏取消归档后进入。

收藏上限为 200 条，默认一次搜索返回 30 条，最多 50 条。写入串行化、去重且可重复调用；持久化失败不会发布成功或替换已确认状态。面向用户的列表保持添加顺序。

## 更新兼容性（0.2.1）

`GET /api/session-favorites/changes` 返回有限 NDJSON 订阅。从进入 `watch` 起（包含等待存储初始化）最多 2.5 秒；初始化未就绪时以 `watch_timeout` / 503 结束。生产期限固定，不提供无限等待配置。这样在桌面更新锁定 API、拒绝新请求后，已有订阅可自然结束，低于已核对的 10 秒排空期限。

每条变更带有收藏 revision 和服务实例内的变更游标。客户端正常 EOF 后平稳轮换，稳定游标不触发额外全量刷新；轮换空隙内的活动或服务重新启动会通过游标变化补刷。503 与异常采用 1、2、4、8、10 秒（上限）退避，恢复后重新同步。始终只保留一条订阅，卸载时取消请求并清理重连计时器。

服务端最多保留一条待消费帧和一条合并后的最新帧，单次响应总输出不超过 4 KiB（触顶可提前结束）；到期、请求 abort、reader cancel 或服务 dispose 都清理定时器、abort 监听与订阅。慢消费者不会无限积压事件。计时器依赖事件循环正常运行，无法对宿主线程长时间阻塞或网络层无限背压提供硬实时保证。

回归包含真实 loopback HTTP 响应体完成、锁定准入返回 503、活跃订阅自然排空、解锁恢复、取消/停用清理、慢消费者、重复启动/重试、客户端卸载与正常轮换不额外刷新。测试还覆盖原有收藏持久化、搜索、并发去重及绿/黄点与已读游标。模拟排空通过不代表插件已经热加载，也不代表真实桌面更新已成功；安装及运行状态需单独核验。
