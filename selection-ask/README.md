# 划词提问 · Selection Ask

在会话框或右侧栏文件中选中文字，点「划词提问」即可就这段内容提问。提问在一个**隐藏会话**里运行：继承当前会话的上下文、模型和权限，可以读写文件，但**不会出现在左侧工作区**。

包名 `dsh-selection-ask`，版本 `0.1.0`，面向 DSH Desktop / Web GUI `0.2.2-rc.1`，Node.js 22+。零 npm 运行时依赖，无安装脚本，不启动额外服务器或后台进程。设计稿见 [selection-ask-design](../selection-ask-design/README.md)。

## 怎么用

1. **会话框**：选中消息正文，原生「引用文本」旁会多出「✦ 划词提问」。选中工具输出、折叠过程等原生不支持引用的地方，选区旁会单独弹出「✦ 划词提问」。
2. **右侧栏文件**：在以下预览中选中文字，选区旁弹出「✦ 划词提问」：
   - 原生预览：代码（带行号）、纯文本（带行号）、Markdown、PDF / Office 文本层、**HTML**；
   - `dsh-better-sidebar` 的文件页：CodeMirror 编辑器（行号取自编辑器状态）、Markdown 预览；其 HTML 预览仅在关闭沙箱（同源）时支持。
3. 点击后在选区旁展开浮窗：自动带上来源（如 `service.js : 42-46`、`report.html · HTML 选区`、`会话框 · 第 2 轮`）和引用片段，输入问题回车即可。浮窗可拖动，`Esc` 或 `×` 收起。
4. 浮窗右上角「固定到侧栏」把这次提问放进右侧栏「划词提问」页签，空间够时会分栏，和正在看的文件并排。右侧栏 `+` 引导页里也能打开这个页签。
5. 「历史 (N)」列出当前会话下的所有划词提问，可切换、继续追问、删除或清空。记录只存在插件里。

6. **图片**：输入框可以粘贴、拖入或点 📎 添加图片（PNG/JPEG/WebP/GIF，每条最多 8 张、单张 10 MB）。图片走 DSH 原生附件存储；当前模型不支持图片时会提示换模型。
7. **模型**：输入框下方显示当前模型和思考强度（默认跟随当前会话）。点开可在提问前或追问时切换，只影响这条划词提问，不改默认模型。

回答按 DSH 原生 Markdown 渲染。AI 需要批准某个操作，或用 `ask_user` 向你提问时，卡片直接出现在浮窗 / 页签里，在那里作答。

## 会话与文件的边界

- 每条划词提问是一个持久的隐藏会话（`origin: 'subagent'`、没有父会话）。左侧工作区、归档列表和主会话的子代理目录都不会显示它。
- 它继承主会话**最后一个已完成轮次**为止的上下文（与原生 fork 同样的种子），以及主会话当前的模型、思考强度、权限预设、沙箱模式和审批策略。插件不提权，也不改全局默认模型。
- 第一次提问前会附加一条说明，告诉模型选区来自哪里、选中内容和前后文，并要求它只回答后续问题、不要继续主会话里未完成的任务。说明只发送一次，不改系统提示词。
- 它和主会话共用工作区。你要求修改时它会真实改文件；文件工具的「先读后写」和版本检查照常生效，shell 改动不受这层保护。
- 闲置 10 分钟后会释放内存中的 Agent，下次追问时从磁盘恢复。每个会话最多保留 50 条，超出时删除最旧的（运行中的不删）。删除提问会同时删除该隐藏会话的日志目录。

## 和桌面更新的兼容性

- 所有接口走已认证的 `ctx.connection.fetch`，不注册原始 Web 路由。
- 界面靠长轮询刷新：每次请求最多等 **2.5 秒**（显著小于更新时宿主 10 秒的排空期限），请求体读取也有 2 秒硬上限，不存在永久响应。
- 宿主锁定时新请求返回 503，客户端按 0.5 s → 15 s 有界退避；收起浮窗、关闭页签或停用插件后不再请求。停用插件会立即结束挂起的请求、取消待答的审批/提问并释放隐藏 Agent。

## 已知边界

- 用户气泡、助手正文的入口复用原生 `conversation.chat.text-interaction` 插槽，与「引用文本」并排；停用插件即恢复原样。
- HTML 预览运行在不透明源的 iframe 里：交互模式下，插件在渲染前往文档里插入一段选区桥接脚本（只发送选中文字、位置和所在章节）；静态模式下，插件把 iframe 的 `sandbox` 从空改为 `allow-same-origin`（**仍不允许脚本**，文档自带的 CSP 也保留），由父页面读取选区。该文档自己的脚本可以伪造选区消息，最多只会弹出一个提问按钮。
- `dsh-better-sidebar` 的 HTML 预览默认是沙箱化的路由页面，插件不改写它；切到它的「关闭沙箱」模式后可划词，或用原生 HTML 预览。
- 嵌入在右侧栏的会话（如岔路分支）里，工具输出等非正文区域的提问会归到当前主会话。
- 隐藏会话的回答在浮窗内逐段刷新（约 120 ms 一次），工具调用只显示名称和成败，不展开参数。
- 已发送的图片在消息里显示为「🖼 N 张图片」，不显示缩略图（隐藏会话不能用原生图片地址）。
- 插件依赖若干 DSH 内部 DOM 属性（`data-textpreview-*`、`data-chat-*`、`data-sidebar-right-*`）和 CodeMirror 6 的 DOM 关联；升级 DSH 后需重新验证。

## 安装与卸载

当前已通过官方插件管理器以 `link:` 方式安装到 `desktop` profile。其他环境：插件 → 安装第三方插件，填写本目录绝对路径（不要填仓库根目录）。卸载时在插件管理器中移除 **划词提问 · Selection Ask**；已有的隐藏会话日志不会自动删除，卸载前可在「历史」里清空。

## 开发与验证

| 文件 | 作用 |
|---|---|
| [context.js](lib/context.js) | 选区校验、边界说明、fork 种子、配置捕获、消息折叠（纯函数） |
| [service.js](lib/service.js) | 隐藏 Agent 创建/恢复/释放、历史存储、审批与提问桥接、长轮询 |
| [index.js](lib/index.js) | 路由、请求体上限与期限、生命周期 |
| [client.js](lib/client.js) | 划词检测、HTML 桥接、浮窗、侧栏页签、历史、退避 |

```sh
npm test                  # 单元测试 + 真实 HTTP 排空/503/卸载测试
npm run test:integration  # 用本机安装包里的真实 DSH 运行时 + 离线假模型
npm run check
```

浏览器级检查：在本目录运行 `python3 -m http.server`，用 Chrome 打开 `tests/browser/fixture.html`，可手动或用 Playwright 验证各类选区读取与 HTML 桥接。
